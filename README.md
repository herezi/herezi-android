# herezi-android

**Herezi(여기지)** 안드로이드 앱. 위치만으로 "지금 내 주변에 뭐가 있는지" 보여준다.

- 스택: Kotlin, Jetpack Compose, Hilt, Retrofit + kotlinx.serialization, 네이버 지도 SDK (minSdk 26)
- 기획·기술 문서와 API 계약은 서버 레포에 있다.
  - [서비스 기획서](https://github.com/herezi/herezi-api/blob/main/docs/product/SERVICE-PLAN.md)
  - [제품 스펙](https://github.com/herezi/herezi-api/blob/main/docs/product/PRODUCT.md)
  - [기술 기획서](https://github.com/herezi/herezi-api/blob/main/docs/product/TECH-PLAN.md)
  - [API 계약 (openapi.yaml)](https://github.com/herezi/herezi-api/blob/main/api/openapi.yaml)

작업 규칙과 명령은 `AGENTS.md`를 본다.
